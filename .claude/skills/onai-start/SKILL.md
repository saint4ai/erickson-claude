# Подготовка к обучению

Перед тобой сотрудник Erickson, который впервые работает с Claude Code и плохо знает компьютер. Твоя задача: самому подготовить компьютер и коротко объяснить, как будет проходить обучение. Человек ничего не устанавливает руками, только разрешает твои действия.

Как говорить: просто, на «Вы», по одному шагу. После каждого шага одна строка: что сделано. Технические подробности, пути и команды не показывай, если человек не спросил. Ставь только то, что перечислено ниже.

## 1. Познакомься

Скажи своими словами, коротко:
- Вы в рабочей папке Erickson. Здесь Claude работает с вашими файлами: таблицами, договорами, выписками.
- На обучении Вы научитесь поручать Claude рутину: прогноз платежей по траншам, договор по шаблону, коммерческое предложение по образцу и отчёт по рекламе.
- Сейчас Claude за несколько минут подготовит компьютер. Если появится вопрос, можно ли выполнить действие, читайте и разрешайте. Чтобы вопросов было меньше, под полем ввода выберите режим Auto.

## 2. Подготовь компьютер

1. Определи систему: Mac или Windows.
2. Python.
   - Mac: проверь `python3 --version`. Если Python не отвечает, запусти `xcode-select --install`. Скажи человеку: «Появится окно, нажмите „Установить“ и подождите от 5 до 15 минут. Когда установка закончится, напишите „Продолжай подготовку“». Дальше не иди, пока он не напишет.
   - Windows: проверь `py --version`, затем `python --version`. Если Python нет, поставь сам: `winget install -e --id Python.Python.3.12 --scope user --accept-package-agreements --accept-source-agreements`. После установки скажи: «Закройте Claude Desktop полностью и откройте снова, выберите эту папку и напишите „Продолжай подготовку“. Без перезапуска Claude не увидит Python». Если winget не работает, дай ссылку https://www.python.org/downloads/ и одной фразой скажи отметить при установке «Add python.exe to PATH».
3. Библиотеки для навыков: `python3 -m pip install --user docxtpl num2words python-docx openpyxl` (на Windows вместо `python3` то, что ответило в шаге 2: `py` или `python`). Если pip пишет externally-managed-environment, повтори с `--break-system-packages`.
4. Проверь, что всё работает: `python3 -c "import docxtpl, num2words, docx, openpyxl; print('ok')"`.
5. Проверь папку: на месте навыки, папка «Учебные данные», «Каталог программ и цен» и три шаблона договора в `.claude/skills/onai-contract/assets/`. Каталог, шаблоны и учебные договоры приходят отдельным архивом документов Erickson. Если их нет, скажи: «Документы Erickson не скачаны, попросите у ведущего ссылку» и продолжай остальные шаги.

Если шаг не получился, объясни причину одной фразой и предложи, что сделать. Не переходи к следующему шагу молча.

## 3. Личные данные

Спроси, какой у человека тариф. Если личный Pro или Max, помоги выключить в настройках Claude: Settings → Privacy → Help improve Claude. Если Team, скажи, что на нём чаты на обучение не идут и делать ничего не нужно. Предупреди: на ответы с данными клиентов не ставят 👍 и 👎.

## 4. Покажи, как всё устроено

Коротко, списком:
- Папка: Claude видит только файлы в ней. Свои файлы для работы кладите сюда.
- Навыки: договор, платежи по траншам, КП по образцу, реклама, 1С. Нужный Claude включает сам по смыслу просьбы.
- «Учебные данные»: выдуманные договоры, выписка и заявка для практики на занятии.
- «Готово»: сюда Claude кладёт готовые файлы.
- Остановить Claude: клавиша Esc или кнопка остановки.

## 5. План занятия

По порядку: платежи по траншам, заявка и договор, коммерческое предложение по образцу (возьмите прошлое КП в Word), аналитика рекламы в Meta. Время скажет ведущий.

## 6. Итог

Коротко: что готово, что осталось сделать человеку. Если всё готово, закончи фразой: «Компьютер готов к обучению».
