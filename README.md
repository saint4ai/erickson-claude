# Erickson-Claude

Рабочая папка для команды Erickson в Claude. В ней лежат правила для Claude, навыки и учебные данные: Claude сам готовит договоры, таблицу платежей, коммерческие предложения, отвечает по Битриксу, 1С и рекламе в Meta.

Документы Erickson (шаблоны договоров, каталог цен, учебные договоры) в репозиторий не входят, участники получают их отдельно.

Начало работы: откройте папку в Claude Desktop и напишите «Начнём».

## Навыки

- `erickson-start`: подготовка компьютера, знакомство с папкой, обновление папки.
- `erickson-contract`: договор по утверждённому шаблону Erickson.
- `erickson-payments`: таблица платежей по траншам, просрочки, напоминания.
- `erickson-kp`: коммерческое предложение по образцу прошлого КП.
- `erickson-bitrix`: Битрикс24, сделки, воронка, ответ клиенту.
- `erickson-1c`: вопросы к 1С, только чтение.
- `erickson-ads`: быстрые вопросы по рекламе Erickson в Meta.
- `karpathy-guidelines`: четыре правила аккуратной работы для любой задачи.
- `humanizer`: живые тексты клиентам и студентам без нейросетевого стиля.
- `ads-agent`: управление рекламой в Meta, главный навык таргетолога.
- `ads-optimizer`: оптимизация кампаний и бюджетов.
- `ads-reporter`: отчёты по рекламе за день, неделю, месяц.
- `campaign-manager`: создание и настройка кампаний.
- `creative-analyzer`: разбор рекламных креативов.
- `creative-copywriter`: тексты для рекламных креативов.
- `targeting-expert`: интересы, аудитории, география.
- `naming-rules`: правила названий кампаний и объявлений.
- `dashboard`: сводка по рекламным аккаунтам.
- `account-onboarding`: подключение нового рекламного аккаунта.
- `account-delete`: удаление рекламного аккаунта из настроек.
- `setup-checklist`: чеклист подготовки Facebook перед первым запуском рекламы.

## Как обновить папку

Отдайте Claude ссылку https://github.com/saint4ai/erickson-claude и попросите обновить папку.
