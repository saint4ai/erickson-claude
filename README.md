# Erickson-Claude

Рабочая папка onAI Academy для обучения команды Erickson работе в Claude Code: правила для Claude, навыки и учебные данные.

Документы Erickson (шаблоны договоров, каталог цен) в репозиторий не входят, участники обучения получают их отдельно.

Начало работы: откройте папку во вкладке Code приложения Claude Desktop и напишите «Начнём».
